# Class notes

- **inbox/**: drop new notes here (PDF, photos, Markdown or plain text). The 2-day cycle picks the next video topic from whatever is in this folder.
- **used/**: notes that already became a video are moved here, so they aren't picked twice.

The notes themselves are git-ignored, because they are course material and shouldn't be published. What gets committed is each video's `notes_brief.md`, a summary of the definitions, examples and claims to fact-check, written for the script.
